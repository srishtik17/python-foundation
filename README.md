Python Foundation 🐍

Welcome to Python Foundation, a collection of Python programs and mini-projects created while learning programming and exploring practical applications.

This repository includes beginner-friendly Python scripts, GUI applications, and experiments with Tkinter and image handling.

📂 Projects & Files
- calculator.py — A Python calculator program
- hello.py — A basic Python program to get started with coding
- tkinter_demo.py — A demonstration of GUI development using Tkinter
- wallpaper_viewer.py — A Python application for viewing wallpapers or images
- favicon.ico — Icon asset used by a project
- flipkart-logo.png — Image asset used by a project
🛠️ Technologies Used
- Python — Programming language
- Tkinter — Graphical user interfaces
- Pillow (PIL) — Image processing, where required
- VS Code — Code editor
- Git & GitHub — Version control and project hosting
🚀 Getting Started

1. Clone the repository:

git clone https://github.com/srishtik17/python-foundation.git

2. Open the project folder:

   cd python-foundation

3. Run a Python file:

   python3 hello.py

To run another program, replace hello.py with its filename.

Install any required libraries before running a project. For example, if a project uses Pillow:

   python3 -m pip install pillow
